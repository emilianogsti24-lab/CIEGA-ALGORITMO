# Búsqueda ciega — Laberinto 5×5

Visualizador interactivo de algoritmos de búsqueda ciega en un laberinto
aleatorio de 5×5.

## Cómo ejecutarlo

Se necesita Python 3. Abre una terminal en esta carpeta y ejecuta:

```bash
python3 CIEGA.PY
```

El programa abrirá el visualizador en el navegador. También puedes abrir
`CIEGA.html` directamente en un navegador moderno.

## Algoritmos disponibles

- Búsqueda en anchura (BFS)
- Búsqueda en profundidad (DFS)
- Búsqueda de costo uniforme
- Búsqueda bidireccional
- Búsqueda en profundidad limitada
- Profundización iterativa

El visualizador anima las celdas que explora cada algoritmo y muestra el camino
que encontró. También permite pausar o reanudar la búsqueda, ajustar la velocidad,
limpiar el resultado y generar otro laberinto.

## Archivos

- `CIEGA.PY`: abre el visualizador en el navegador.
- `CIEGA.html`: interfaz, generación de laberintos y algoritmos.
